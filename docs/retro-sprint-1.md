# Sprint 1 retrospective
## Sprint Goals
Make a database and CRUD. Staff should be able to upload a book. Members can borrow, reserve, and return a book.

## How did it go?
We think this sprint went well. As of today all the tasks that we added to the sprint have been finished, with the exception of a few which are being worked on to be finished soon.

## Things to change
For the next sprint, we will make the following changes:
* Add a column to the board for tasks that are in review.
* Review pull requests more. Having more people give their opinion and suggestions improves collaboration and the quality of the code.
* Write more detailed task descriptions from now on. Include more details in the descriptions, for instance which functions could be needed for the task and in what files they should be placed, or which API endpoints should be used. 
* Make tasks smaller if possible. Smaller tasks leads to smaller pull requests which are easier to review.
